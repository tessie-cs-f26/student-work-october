# Student Python Showcase

Programs written by students in our intro Python class. Open a program to run it right in your browser.

| Program | Student | What it does |
|---|---|---|
| [Baking Measurement](programs/baking/) | Samika | Converts units of measurement used in baking. |
| [Baseball](programs/baseball/) | Noah | Computes advanced baseball stats from fundamental ones. |
| [Grade Calculator](programs/grade/) | Jasmina | Computes the average grade over multiple classes. |
| [Metric Converter](programs/metric/) | Wyatt | Converts units from metric to imperial and back. |
| [Tip Calculator](programs/tip/) | Ben | Calculates the tip needed for a meal. |
