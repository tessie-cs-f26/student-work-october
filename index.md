# Student Python Showcase

Programs written by students in our intro Python class. Open a program to run it right in your browser.

| Program | Student | What it does |
|---|---|---|
| [Baking Measurement](programs/baking/) | S. H. | Converts units of measurement used in baking. |
| [Baseball](programs/baseball/) | N. D. | Computes advanced baseball stats from fundamental ones. |
| [Grade Calculator](programs/grade/) | J. H. | Computes the average grade over multiple classes. |
| [Metric Converter](programs/metric/) | W. A. | Converts units from metric to imperial and back. |
| [Tip Calculator](programs/tip/) | B. Z. | Calculates the tip needed for a meal. |
